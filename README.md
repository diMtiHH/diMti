# Спроси Вселенную / Ask the Universe

«Один вопрос. Один ответ. Тридцать минут тишины».

Приложение для безопасных бытовых вопросов о собственных действиях. Ответ
случайный; приложение не предсказывает будущее и не даёт профессиональных советов.
Источник требований: [мастер-промпт v2.0](docs/source/MASTER_PROMPT_v2.txt).

**Этап 1 завершён и принят. Локальная проверка RU/EN работает с закрытым допуском для всех вопросов.**
Запуск с моделью в подготовленной среде — `.venv/bin/python -m research.stage_one`.
Для воспроизведения обучения и контроля используйте [отчёт этапа 1](docs/STAGE_1.md).

**Этап 2 завершён по решению основателя; начат этап 3.** iPhone Air прошёл физические проверки локальной модели, авиарежима и отказа без модели. [Отчёт этапа 2 и сохранённые ограничения](docs/STAGE_2.md).

Для локальной проверки на Windows x64 запустите `setup-windows.cmd`. Последний результат: **63/63 теста**, анализ без замечаний. Для 0.3.3 (5) добавлены и пройдены **16/16 нативных проверок** часов и уведомлений; IPA собран и проверен, **2/2 интеграционных теста** iOS 18.5 прошли на том же коммите. Ядро подключено к новому экрану, приватному хранилищу, часам и уведомлениям iPhone. Положительный технический сценарий изолирован в «Проверке ядра» с фиксированным примером; начиная с версии 0.3.2 (4), новые тестовые паузы занимают 1 минуту, обычные сохраняют 30 минут. Допуск реальных вопросов закрыт. Ручные проверки отложены по просьбе основателя; разработка этапа 3 продолжается. [Результаты сборки](PROJECT_STATUS.md) · [Проверка новой версии на iPhone](docs/STAGE_3_DEVICE_CHECK.md) · [Этап 3](docs/STAGE_3.md).

## Минимальный стенд без модели (этап 0)

Нужны Git и Python 3.12; проверенная версия — 3.12.14 (`.python-version`).
Внешних Python-зависимостей, ключей, регистрации и скачивания моделей нет.
Из корня репозитория:

```bash
python3 -m bench
python3 -m unittest discover -s tests -p test_validation.py -v
```

В текущем облаке корень — `/workspace/diMti`. На другом компьютере перейдите
в каталог своей копии репозитория. Сборка для запуска Python-стенда не нужна.

Первая команда проверяет два встроенных публичных примера RU/EN. Ожидается
`passed: true`, для каждого примера — `ERROR` / `model_unavailable`.
Это **успешная проверка отказа при отсутствии модели**, а не успешная
классификация вопроса. Код возврата 0 означает, что ожидаемый отказ проверен;
1 — что проверка стенда не прошла. Команда не принимает личные вопросы.

Тесты используют искусственные ответы адаптера для проверки его контракта.
Они не измеряют безопасность нейросети. Случайные ответы, таймер, микрофон,
сеть и мобильный интерфейс в стенде не реализованы.

## Продолжение работы

Сначала прочитать `PROJECT_STATUS.md` и исходное ТЗ. Не считать предложение
утверждённым решением и тест стенда — приёмкой этапа. Каждый следующий этап
начинается после явного подтверждения основателя. Содержимое личных вопросов,
аудио и секреты не добавлять в репозиторий, логи или тестовые наборы.
