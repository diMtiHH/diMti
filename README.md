# Спроси Вселенную / Ask the Universe

«Один вопрос. Один ответ. Тридцать минут тишины».

Приложение для безопасных бытовых вопросов о собственных действиях. Ответ
случайный; приложение не предсказывает будущее и не даёт профессиональных советов.
Источники требований: [мастер-промпт v2.0](docs/source/MASTER_PROMPT_v2.txt) и
[визуальная система AURA 13](docs/source/MASTER_PROMPT_AURA13.txt).

**Этап 1 завершён и принят. Локальная проверка RU/EN работает с закрытым допуском для всех вопросов.**
Запуск с моделью в подготовленной среде — `.venv/bin/python -m research.stage_one`.
Для воспроизведения обучения и контроля используйте [отчёт этапа 1](docs/STAGE_1.md).

**По решению основателя идёт этап 6: AURA 13, версия 0.6.0 (10).**
Допуск всех реальных вопросов остаётся закрытым; ручные проверки сейчас не
запрашиваются. Предыдущая версия сохранена в [основе этапа 5](docs/STAGE_5_BASELINE.md).
Реализованный объём, архитектура и ограничения — в [отчёте этапа 6](docs/STAGE_6.md).
AURA 13 — название визуальной системы; публичное название приложения сохраняется.

Встроены четыре пространства — звёздная пустота, галактика, полярное сияние и
гравитация — и четыре независимые формы: живая материя, жидкий металл,
бесконечность и созвездие. GPU-шейдеры и процедурная геометрия реагируют на жесты,
ввод и амплитуду локального микрофона. Обновлены основной экран, ввод,
подтверждение, настройки с живыми каруселями и полноэкранный ответ. Последовательность
показа получает уже сохранённый результат ядра; она не выбирает ответ и не
обходит модель. Таймер начинается после видимого кадра ответа.

Manrope RU/EN поставляется реальными файлами с SIL OFL; оригинальный векторный
знак используется в интерфейсе и непрозрачных app icons. Четыре оригинальных
ambient WAV и три коротких нейтральных отклика подготовлены офлайн и по умолчанию
выключены; микрофон, фон и аудиопрерывания останавливают их. Для ДА и НЕТ звучит
один и тот же отклик. После прерывания требуется новое явное включение.
Знакомство, локальное необязательное имя и версия согласия сохранены. Озвучка
знакомства Pavel/Zira и ambient пока временные, английский текст не утверждён.
«Что волнует мир» — будущий раздел без сбора данных и вымышленных счётчиков.

Для локальной проверки на Windows x64 используется `setup-windows.cmd`.

## Минимальный стенд без модели (этап 0)

Нужны Git и Python 3.12; проверенная версия — 3.12.14 (`.python-version`).
Внешних Python-зависимостей, ключей, регистрации и скачивания моделей нет.
Из корня репозитория:

```bash
python3 -m bench
python3 -m unittest discover -s tests -p test_validation.py -v
```

В текущем облаке корень — `/workspace/diMti`. На другом компьютере перейдите
в каталог своей копии репозитория. Сборка для запуска Python-стенда не нужна.

Первая команда проверяет два встроенных публичных примера RU/EN. Ожидается
`passed: true`, для каждого примера — `ERROR` / `model_unavailable`.
Это **успешная проверка отказа при отсутствии модели**, а не успешная
классификация вопроса. Код возврата 0 означает, что ожидаемый отказ проверен;
1 — что проверка стенда не прошла. Команда не принимает личные вопросы.

Тесты используют искусственные ответы адаптера для проверки его контракта.
Они не измеряют безопасность нейросети. Случайные ответы, таймер, микрофон,
сеть и мобильный интерфейс в стенде не реализованы.
