## Исполненные проверки этапа 0

Команда: `python3 -m unittest discover -s tests -v`.
Файл: `tests/test_validation.py`.

- `test_missing_model_blocks_both_languages`: RU/EN без модели → ERROR.
- `test_missing_model_does_not_guess_from_question`: отсутствующая модель
  не разрешает даже внешне простую/неясную/опасную формулировку.
- `test_empty_or_non_text_input_does_not_call_adapter`: неверный вход → отказ.
- `test_unsupported_language_does_not_call_adapter`: неподдерживаемый язык → UNCERTAIN.
- `test_adapter_failure_is_closed_and_does_not_expose_text`: исключение → ERROR,
  сообщение исключения не попадает в stdout/stderr/результат.
- `test_malformed_adapter_outputs_are_closed`: неверный формат/статус → ERROR.
- `test_typed_verdicts_are_preserved_without_generating_answers`: контракт пяти
  состояний с искусственным адаптером, без случайного ответа.
- `test_full_text_reaches_adapter_without_truncation`: исходный контекст не обрезается.
- `test_result_contains_no_question_or_audio_fields`: ответ интерфейса — только коды.
- `test_cli_checks_missing_model_and_returns_success`: реальный запуск модуля,
  два результата RU/EN и успешный статус проверки ожидаемого отказа.

Тесты не проверяют смысловую безопасность, качество распознавания языков,
физическое удаление памяти или приватность ещё не написанного приложения.
