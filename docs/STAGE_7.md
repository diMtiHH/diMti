# Этап 7 — «Что волнует мир»

Реализация входит в личную сборку **0.8.0 (14)** вместе с этапом 8. Основание — просьба основателя 27 ноября 2026 выполнить оба этапа и разрешить ответы с временным сбросом лимита. Это изменение прежнего режима закрытого допуска, а не приёмка исследовательской модели для публичного запуска.

## Экран и каталог

Восемь двуязычных формулировок о чтении, музыке, рисовании и других занятиях с небольшими последствиями. Каталог явно отделён от рейтинга; подготовленные примеры не выдаются за вопросы пользователей. Касание переносит формулировку в редактор основной вкладки. Подтверждение, модель, генератор и пауза проходят через прежнее ядро. Касание само не выбирает ответ. Во время паузы каталог доступен, но начать новую попытку нельзя.

Рейтинг поддерживает сутки, неделю, месяц; выбранный язык или весь мир. Подписи и формулировки RU/EN. Сервер возвращает только идентификаторы известных тем. Неизвестные поля и темы, неподходящие счётчики, период, язык или дата отклоняются. Последний успешный ответ сохраняется отдельно для каждого фильтра и явно показывается как кеш при отсутствии сети. Пустой рейтинг не заполняется придуманными числами.

## Данные и согласие

Согласие выключено по умолчанию, запрашивается отдельно с описанием полей и ограничений. Локальная очередь содержит только `topic`, `language`, `day` (UTC), `count`. Нет исходного вопроса, ответа, имени, аудио, устройства или профиля. Разные личные тексты не сопоставляются по приблизительному смыслу: только полное совпадение с маленьким проверяемым каталогом. Это ограничение намеренно.

Счётчики добавляются после успешной фиксации ожидающего ответа. Пакет получает случайную квитанцию только для безопасного повтора загрузки; после подтверждения она удаляется. Квитанция не является идентификатором установки. При отзыве согласия прекращается добавление, отменяется сеть, удаляются очередь и незавершённый пакет. Поздний ответ сети не восстанавливает согласие или данные. Уже объединённые серверные итоги нельзя выделить по человеку и удалить отдельно; это объясняется до согласия.

**Личная сборка с кнопкой сброса не отправляет счётчики**, даже при включённом согласии. Это предотвращает попадание повторных технических прогонов в публичные итоги.

## API и хранение

`server/world_api.py` — API на стандартной библиотеке Python и SQLite. `POST /v1/counts`: строгая схема, ограничения размера и количества, проверка каталога/дат, транзакция и идемпотентная квитанция. `GET /v1/ranking`: только завершённые дни UTC, минимум 10 вопросов, округление вниз до 5, максимум 100 тем (сейчас каталог содержит 8). Считаются вопросы, не уникальные люди.

Хранятся дневные итоги до 30 дней и квитанции до 35 дней; очистка выполняется при обращении к API. При остановленном сервисе очистка не работает до следующего запуска/запроса. Технический сетевой адрес используется для ограничителя запросов только в ограниченной оперативной памяти с солью процесса; журналы HTTP отключены. Это базовое ограничение накрутки, не доказательство анонимности или защиты от распределённых атак. До публичного подключения нужны HTTPS, проверка журналов посредников и эксплуатационные лимиты.

```powershell
python -m unittest server.test_world_api -v
python -m server.world_api --database world.sqlite3 --port 8080
```

По умолчанию сервис помечает данные `environment=test`, и приложение показывает эту маркировку. Для производственного сервера предусмотрен отдельный `--production`. Локальный сервер слушает только `127.0.0.1`; клиент принимает только HTTPS-origin без логина, пути, query или fragment, не следует перенаправлениям.

**Публичный сервер не развёрнут, адрес и платный хостинг не выбраны.** В IPA `UNIVERSE_WORLD_API` пуст: сетевых запросов нет, каталог доступен офлайн, экран сообщает, что статистика ещё не подключена. Реальные HTTP-запросы и агрегирование проверяются автоматически на изолированном локальном сервере. Подключение настоящей статистики требует адреса HTTPS и отдельного эксплуатационного решения; вымышленных пользователей и чисел в IPA нет.

## Личный допуск

Исследовательская модель, контрольные суммы и её диагностический закрытый результат не изменены. `PersonalTestGate` допускает только полную каталожную формулировку, **дополнительно классифицированную моделью как ALLOW с прежним порогом**. Риск, сомнение, ошибка, изменение смысла и добавленный контекст не проходят. Все 16 канонических вариантов RU/EN проверяются настоящей упакованной моделью. Публичный режим `UNIVERSE_PERSONAL_TEST=false` закрывает этот допуск и временный сброс. Это не общий допуск свободных вопросов и не подтверждение качества модели для открытой публикации.

Проверки очереди, кеша, согласия, ошибок и гонок — `mobile/test/world_data_test.dart`; границы допуска и сброса — `personal_gate_test.dart`; реальная модель — `personal_catalog_model_test.dart`; HTTP/SQLite — `server/test_world_api.py`. Нативные проверки дополняют существующую атомарную запись и iOS XCTest.
