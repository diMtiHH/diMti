# Bundled offline typography — 0.6.2

Headings use **Cormorant Garamond** (Light 300, Regular 400, Medium 500, SemiBold 600). Main-screen body text uses **Literata** (Regular 400, Medium 500, SemiBold 600), instantiated at optical size 14. The approved Constellation settings design pairs the existing headings with **Manrope Regular 400 and Medium 500** for compact descriptions and controls, using the unchanged files previously prepared for 0.6.0. Its license is `OFL.txt`; the official source is the same pinned Google Fonts commit under `ofl/manrope`.

All three families come from official Google Fonts at pinned commit `b31870aff700ab7a1d74fa0c6887d95beb9e0037`: [Cormorant Garamond](https://github.com/google/fonts/tree/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/cormorantgaramond), [Literata](https://github.com/google/fonts/tree/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/literata), and [Manrope](https://github.com/google/fonts/tree/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope). Copyright remains with their respective Project Authors. Unmodified SIL Open Font License 1.1 texts are shipped as `CormorantGaramond-OFL.txt`, `Literata-OFL.txt`, and `OFL.txt`.

`sources.json` records source URLs, SHA-256 hashes, byte counts, fixed axes and all nine registered static faces. Preparation checked Russian Cyrillic including Ё/ё, Latin, digits and punctuation, weight metadata and absence of variable axes. No glyph subsetting or outline redesign was applied. Literata instance names identify their static weights.

Rebuild with `python mobile/tool/prepare_cosmic_fonts.py --fonttools-path <temporary fonttools 4.61.1 directory>`. FontTools is only an asset-preparation dependency. Source TTFs and upstream metadata preserve provenance; runtime loads nine registered static faces and three licenses without any font download. Manrope Light and SemiBold remain historical evidence and are not packaged.
